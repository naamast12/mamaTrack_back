# MamaTrack – Backend 💻

The backend of the **MamaTrack** pregnancy app, built with **Spring Boot (Java)** and **Supabase**.  
It provides secure APIs for user management, weekly updates, checklists, contraction tracking, and more.

## 🔑 Key Features
- 🔐 **JWT Authentication** – secure login and protected routes  
- 👩‍🍼 **User & Profile API** – stores user info, due date, and pregnancy week  
- 📆 **Weekly Updates API** – returns week-specific pregnancy info from Supabase  
- 🧾 **Checklists API** – manages personalized baby and hospital lists  
- ⏱️ **Contraction Timer API** – start/stop contractions and view history  
- 💬 **Community Integration** – supports chats for both general and trimester-based groups  
- 🌐 **Deployed on Render** – cloud-hosted and connected to the frontend

## 🧩 Tech Stack
**Language:** Java  
**Framework:** Spring Boot  
**Database:** Supabase (PostgreSQL)  
**Auth:** JWT (JSON Web Token)  
**Deployment:** Render
